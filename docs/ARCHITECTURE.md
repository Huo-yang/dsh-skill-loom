# Skill Loom 架构

## 角色和能力族

角色是会话可绑定的技能依赖图。角色有显示名、可选简介、人设、技能集合与依赖边。边的存储方向为 from → to，含义是 from 需要 to。画布把前置技能画在上方，使用它的技能画在下方。

能力族是可重复插入的技能子图。预览使用虚拟根。插入时，把虚拟根下的技能接到目标节点。目标是角色根时直接纳入技能，目标是技能时追加对应依赖。合并会共享同名技能，保留已有边，补齐缺失依赖。会形成环的图无法保存。

## 健康和会话

graph.js 检查可解析技能和依赖闭包。找不到的技能为红，依赖红色或灰色技能的节点为灰。健康节点进入运行时集合。技能锚点记录保存时的来源，供解释缺失与漂移。

runtime.js 在绑定 Agent 的作用域内，把其余技能注册为不可调用的同名覆盖项，从该会话的技能目录排除，并安装角色的人设段。解绑时撤销这些注册。文件、命令与网络权限由 DSH 管理。其他 Agent 的技能目录独立。

catalog.js 汇总全局和活跃作用域的技能供编排。运行时按目标 Agent 的实际技能计算健康。技能注册变化时，宿主防抖刷新现有绑定。

## 草稿、存储和接口

- client.js 提供 Web 主页面与会话右侧页签。图编辑、撤销和重做先在草稿上进行。浏览器存储只保存未提交的草稿，刷新可恢复。
- http.js 提供 /skill-loom 下的角色、能力族、绑定和检查请求接口。角色图预览使用正式保存路径的校验和规划逻辑。保存带 revision，冲突时保留浏览器草稿。
- store.js 以临时文件加原子重命名保存对象。默认数据根为 $DSH_HOME/roles，未设置 DSH_HOME 时使用 ~/.dsh/roles。角色保存在此目录，能力族位于 families 子目录，会话绑定在 bindings.json。
- index.js 挂载 DSH 服务、串行化写操作并刷新已绑定的 Agent。宿主的角色版本历史保存在内存。

## DSH 自助编排

role_graph 创建、检查和修改角色，可绑定当前会话。role_family 创建、修改或把能力族合入角色。role_spawn 用指定角色运行子 Agent。role_review 把已保存的检查目标交给当前 Web 会话，客户端通过 DSH 右侧栏服务打开对应依赖图。

预置能力族「技能编排助手」由编排和检查技能组成。技能通过宿主全局注册，仍受会话角色的技能可用性规则约束。
